## Current verification boundary

This public repository is a controlled demonstration. It does not claim:

- production certification
- a live external institutional pilot
- regulatory approval
- market validation
- independent penetration-test clearance
- production-calibrated causal validity
- financial outcome guarantees

## Intellectual-property boundary

The repository intentionally omits protected trade-secret implementation details, confidential data-room materials, transaction valuation and negotiation logic, sensitive chain-of-title records, production secrets, and buyer-specific acquisition materials.

## Public due-diligence use

An evaluator can inspect the source, run the tests, execute the Flask API, use the static browser demonstration, review commit history, and verify that the public artifact preserves the core governance boundary: analytical outputs do not create autonomous material execution authority.
