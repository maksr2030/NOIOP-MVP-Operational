# NOIOP Public MVP Architecture Overview

The public operational MVP is intentionally separated from confidential acquisition and trade-secret materials.

## Layers

1. Public Interface
   - Browser-based interactive assessment
   - Public-safe explanatory interface

2. Application Runtime
   - Flask HTTP service
   - Health endpoint
   - Opportunity assessment endpoint

3. Governed Assessment Engine
   - Bounded normalized signals
   - Deterministic weighted scoring
   - Explicit abstention conditions
   - No autonomous material execution authority

4. Evidence Layer
   - Canonical deterministic output hashing
   - Public evidence hash for reproducibility

5. Verification Layer
   - Automated tests
   - GitHub Actions continuous integration

## Public versus confidential boundary

The public repository demonstrates operating principles and reproducible runtime behavior. It excludes proprietary feature implementation details, confidential architecture records, buyer materials, private evidence packs, valuation logic, negotiation information, and private chain-of-title documents.

## Current public non-claims

This repository does not constitute production certification, regulatory approval, market validation, external institutional pilot evidence, or independent penetration-test clearance.
